## 🚀 Featured Projects

### 🤝 Common Ground — AI Workplace Mediation Platform
> Helps two people prepare for a hard workplace conversation, like a performance review or raise request. Each person does a private AI interview, then the platform compares both sides and writes a meeting preparation brief. Built on a durable LangGraph state machine with PostgreSQL checkpointing, crisis detection, grounding checks so AI rewrites never add claims a user did not make, and nightly evaluation runs against real models. Live in pilot.  
`LangGraph` `FastAPI` `PostgreSQL` `OpenRouter` `Terraform` `AWS ECS Fargate`

> AI-powered financial assistant for a US addiction treatment provider. Unified 5 platforms (EHR, CRM, call tracking, and ad accounts) into a single conversational interface with LangGraph supervisor + 3 sub-agents, SSE streaming, and HIPAA-aware role-based access for C-suite healthcare leadership.  
`FastAPI` `LangGraph` `PostgreSQL` `AWS` `SSE Streaming` `Multi-Agent`
